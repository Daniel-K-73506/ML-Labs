Lab 2 — Network design

Input 64 → hidden W → ReLU → hidden W → ReLU → output 10 → softmax

The network

Each line is one weight. Hover over a group of lines to see its weight matrix. Columns with more than 16 neurons are shortened with ⋮.

Shapes and parameter count (W = 16)

ConnectionWeightsrows × colscountBiascount

Rule: weight shape = (neurons on the left, neurons on the right). There is one bias per neuron on the right. Total = W² + 76W + 10, so W=16 gives 1,482 and W=64 gives 8,970.

Equations for one batch of B images

Z1 = X·W1 + b1   (B,64)·(64,W) → (B,W)
    A1 = ReLU(Z1) = max(0, Z1)
Z2 = A1·W2 + b2  (B,W)·(W,W) → (B,W)
    A2 = ReLU(Z2)
Z3 = A2·W3 + b3  (B,W)·(W,10) → (B,10)
    P = softmax(Z3)  each row sums to 1

For a matrix product to work, the inner dimensions must match: (B,64)·(64,W).

Initialisation

Weights ~ N(0, 0.01) (std 0.01): small and random, which breaks symmetry. Biases = 0. Because the weights are tiny, the logits Z3 are close to 0, so softmax gives each class about 0.1. The untrained loss is therefore about −ln(0.1) = ln(10) ≈ 2.3026, which is the Task 4 sanity check.
